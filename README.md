**CRC-24/BLE Functional Verification Testbench**
A SystemVerilog functional coverage testbench for a CRC-24/BLE hardware engine — CRC algorithm used in Bluetooth Low Energy advertising and data channel packets.

The project covers RTL design, a software golden model, directed stimulus, edge case testing, and full functional coverage closure

What's verified:

Correct CRC computation against the BLE polynomial (x²⁴ + x¹⁰ + x⁹ + x⁶ + x⁴ + x³ + x + 1)
LSB-first bit ordering per the BLE specification
Configurable CRC initialization, including the BLE advertising default (0x555555)
Reset behavior (idle, between-transaction, and mid-transaction)
Gap cycles, back-to-back transactions, and known hand-computed reference vectors
100% functional coverage across 9 coverpoints and 5 cross coverpoints
Built using AI agents — the verification plan was generated by ChatGPT, then used as a specification to iteratively build and close coverage with Claude. The workflow mirrors how an engineer might use AI-assisted development: spec → RTL → testbench → coverage closure → documentation.

Runs on EDA Playground under VCS or Xcelium with no external dependencies.
